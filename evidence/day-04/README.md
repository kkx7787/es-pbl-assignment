# Day 4 제출 파일

아래 파일을 개인 저장소의 `evidence/day-04/`에 저장합니다.

- `dashboard-plan.md`
- `dashboard-review.md`
- `common-dashboard.png`: 공통 6패널과 control이 보이는 전체 화면
- `personal-dashboard.png`: 개인 4패널 이상과 제목이 보이는 전체 화면
- `personal-dashboard-filtered.png`: filter/control 적용 상태
- 선택: `dashboard.ndjson` 또는 강사가 지정한 내보내기 파일

현재 수업용 Kibana 9.5.0에서 PDF 메뉴가 없어도 정상입니다. 화면 캡처가 기본 근거입니다. Dashboard `More → Export`의 JSON 또는 `Stack Management → Kibana → Saved Objects → Export`의 NDJSON은 선택 백업으로 제출합니다.

교시별 연습문제 답안은 별도 `evidence/day-04-practice/`에 저장합니다. 문제지의 모든 문항을 이 폴더에 다시 복사하지 않고, `day-04-practice/period-01-*.md`부터 `period-08-*.md`까지 작성본을 유지합니다.

## 캡처 기준

- Dashboard 제목, 시간 범위, filter/control, 패널 제목과 값이 읽혀야 합니다.
- 비밀번호, API key, 개인 토큰, `.env` 내용은 포함하지 않습니다.
- 오류 화면을 제출할 때는 주소창이나 개인정보보다 오류 메시지와 현재 단계가 보이게 캡처합니다.

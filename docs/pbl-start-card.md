# PBL 시작 카드

- **프로젝트 주제:** 26/27 시즌 프리미어리그 스카우팅 선수 검색

- **사용자는 누구인가:**
  프리미어리그 구단에서 하위 리그·유스 자원 영입을 검토하는 스카우팅 리서처

- **ES로 찾게 할 문서 1건은 무엇인가:**
  선수 1명

- **사용자가 입력할 검색 질문 1 (자유 검색):**
  "왼발 윙어", "전진 패스" 같은 표현으로 스카우팅 코멘트와 이름을 검색한다.

- **사용자가 입력할 검색 질문 2 (조건 검색):**
  22세 이하이면서 홈그로운 자격이 있고, 주발이 왼발이며 레프트윙을 소화할 수 있는 선수를 찾는다.

- **사용자가 입력할 검색 질문 3 (Dashboard):**
  홈그로운 자격이 있는 22세 이하 자원이 리그별·포지션별로 어디에 몰려 있는지 확인한다.

- **필터에 사용할 분류 field 후보:**
  리그(`league`), 소속 구단(`club`), 주 포지션(`detailed_position`),
  주발(`preferred_foot`), 홈그로운 여부(`is_homegrown`)

- **정렬에 사용할 숫자·날짜 field 후보:**
  나이(`age`), 출전 시간(`stats.minutes`), 시장 가치(`market_value_eur`),
  계약 만료일(`contract_until`)

- **Dashboard에서 답할 질문 1:**
  홈그로운 자격이 있는 22세 이하 자원이 부족한 포지션은 어디인가?

---

## 왜 홈그로운을 핵심 조건으로 잡았는가

프리미어리그는 25인 스쿼드에 홈그로운 선수를 최소 8명 등록해야 한다.
21세 이하 선수는 이 25인에 포함되지 않는다.
그래서 스카우팅 리서처에게 "나이"와 "홈그로운 자격"은
단순한 인적 사항이 아니라 **등록 가능 여부를 가르는 조건**이다.
이 프로젝트의 조건 검색이 실제 업무 질문과 맞아떨어지는 지점이다.

---

## 범위 확인

- 웹사이트 전체를 만드는 과제가 아니다. ES index, 검색 요청, 분석·Dashboard를 완성한다.
- 실제 개인정보·고객 데이터는 사용하지 않는다. 선수 정보는 전부 합성 데이터다.
- 최소 1,000건, 권장 5,000~10,000건의 합성 데이터를 사용한다.
  이 프로젝트는 **약 6,000건**을 목표로 한다.

### 6,000건 구성 (Day 2에 확정)

| 티어 | 범위 | 구단 수 | 선수 수(약) |
|---|---|---:|---:|
| 1 | 프리미어리그 1군 | 20 | 500 |
| 2 | 프리미어리그 U21 아카데미 | 20 | 400 |
| 3 | EFL (Championship / League One / League Two) | 72 | 1,800 |
| 4 | 유럽 주요 리그 (라리가·분데스리가·세리에A·리그앙 외) | 128 | 3,200 |
| | **합계** | **240** | **약 5,900** |

> 사용자가 "하위 리그와 유스 자원을 검토하는 스카우팅 리서처"이므로,
> 검색 대상이 프리미어리그 1군에만 한정되면 사용자 정의와 맞지 않는다.
> 티어 2·3·4가 실제 스카우팅 대상이고, 티어 1은 비교 기준이 된다.
